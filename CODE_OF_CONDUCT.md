# Code of conduct

This is a small community project. Contributors, maintainers and users should communicate respectfully.

Be constructive; focus on technical details and reproducible evidence. Harassment, personal attacks, discrimination, doxxing, spam and deliberately unsafe advice are not accepted. Respect users' privacy and do not ask them to post keys, pairing secrets or private network information.

The maintainer may moderate discussions, edit or close off-topic comments, and restrict participation when necessary. Report conduct concerns through [GitHub Issues](https://github.com/dmitriy1ebedev/venta-aw730-homeassistant/issues) without posting personal or sensitive evidence. For security vulnerabilities, use [SECURITY.md](SECURITY.md).
