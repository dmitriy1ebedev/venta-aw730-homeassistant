# ROADMAP — Venta AW730 Home Assistant

Единый план развития и приёмки проекта. Источник истины — этот файл в Git; текущую реализацию и правила безопасности см. в README.ru.md, docs/architecture.md, docs/MAINTAINING.md и AGENTS.md.
План согласован владельцем 22.11.2026. Он не разрешает самовольную перенастройку или перезапуск живого Home Assistant, изменения физической мойки и сопряжений Apple Home.
Команды «продолжаем по роудмапу» достаточно, чтобы в новом чате открыть этот файл и приступить к следующему доступному пункту с проверками через MCPshka.

Статусы пунктов: [ ] — не начато; [-] — выполняется или ожидает доказательств; [x] — выполнено и принято. Не закрывать пункт по одному коммиту или одной зелёной CI-проверке.
Порядок: версия 1.0.5 → 1.1.0 → 1.2.0 → 1.3.0 → решение по 2.0.0. Сроки ориентировочные, приоритет — критерии Exit.
Пункты считаются выполненными только по доказанному Exit и отметке [x], даже если соответствующая версия уже установлена. Эксплуатационная приёмка 1.2.0 не заменяет GitHub Release, GitVerse CI и защищённую проверку выпуска.
